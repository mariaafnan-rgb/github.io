# Maria Afnan — Academic Portfolio

A responsive academic portfolio website built with HTML, CSS, and a small amount of JavaScript.

## Files
- `index.html` — page content and structure
- `style.css` — layout, colors, typography, and responsive styling
- `script.js` — mobile navigation and footer year
- `assets/` — place your profile photo and other assets here

## Publish with GitHub Pages
1. Create a public repository named `mariaafnan-rgb.github.io`.
2. Upload all files and folders from this project to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Visit `https://mariaafnan-rgb.github.io/` after deployment finishes.

## Personalize before publishing
- Replace the profile-photo placeholder by adding `assets/profile.jpg` and updating the placeholder block in `index.html` to an `<img>` element.
- Add links to Google Scholar, LinkedIn, ORCID, publications, and your CV when available.
- Review project descriptions and only add claims, publications, or results that are ready to share.
